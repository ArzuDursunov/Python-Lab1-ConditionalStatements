# 🐍 Mini Python Projects

A small collection of three beginner-friendly Python programs: a BMI calculator, a birthday guessing game, and a Chinese zodiac finder.

## 📂 Projects

| Project | File | Description |
|---------|------|-------------|
| ⚖️ BMI Calculator | `bmi_calculator.py` | Calculates your Body Mass Index from your weight and height |
| 🎂 Birthday Guesser Game | `birthday_guesser.py` | A fun game that tries to guess your birthday |
| 🐉 Chinese Zodiac Finder | `chinese_zodiac.py` | Finds your Chinese zodiac animal from your birth year |

> **Note:** If your file names are different, update the names in the table above and in the commands below.

---

## ⚖️ 1. BMI Calculator

Enter your weight and height, and the program calculates your BMI and tells you which category you fall into.

**BMI categories:**

| BMI | Category |
|-----|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal weight |
| 25 – 29.9 | Overweight |
| 30 and above | Obese |

**Run it:**
```bash
python bmi_calculator.py
```

> BMI is only a general guide and doesn't replace advice from a doctor.
